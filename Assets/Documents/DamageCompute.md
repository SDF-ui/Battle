## 1. 基础属性系统

### 1.1 四大基础属性

| 属性 | 英文 | 影响 |
|------|------|------|
| 体质 | CON | 生命值、防御力 |
| 灵力 | INT | 内力值、少量命中率、少量暴击率 |
| 力量 | STR | 攻击力、暴击率、命中率 |
| 敏捷 | AGI | 速度、闪避率、少量命中率 |

### 1.2 属性构成

```
最终CON = 10 + allocatedCON + extraCON + 装备体质 + 法宝体质
最终INT = 10 + allocatedINT + extraINT + 装备灵力 + 法宝灵力
最终STR = 10 + allocatedSTR + extraSTR + 装备力量 + 法宝力量
最终AGI = 10 + allocatedAGI + extraAGI + 装备敏捷 + 法宝敏捷
```

- **基础分配**（allocated）：每升一级获得4点属性点，1~70级共276点
- **额外加成**（extra）：人参果最多120个，每个+1点
- **装备/法宝加成**：通过 `AttributeHelper.AddItemsAttributes()` 累加计算

参考：`CharacterStatsCalculator.CalculateFinalStats()`

## 2. 战斗属性计算

### 2.1 主属性公式（基础值）

| 战斗属性 | 计算公式 |
|---------|---------|
| **生命值 (HP)** | `CON × 20 + Level × 50 + 1000 + 装备HP + 法宝HP` |
| **内力值 (MP)** | `INT × 5 + Level × 20 + 300 + 装备MP + 法宝MP` |
| **攻击力 (ATK)** | `STR × 6 + Level × 25 + 200 + 装备ATK + 法宝ATK` |
| **防御力 (DEF)** | `CON × 4 + Level × 15 + 120 + 装备DEF + 法宝DEF` |
| **速度 (SPD)** | `AGI × 0.75 + Level × 0.5 + 500 + 装备SPD + 法宝SPD` |

### 2.2 概率属性公式（百分比）

| 属性 | 基础公式 | 门派基础加成 |
|------|---------|-------------|
| **暴击率** | `(STR × 0.05 + INT × 0.05) / 100 + Level × 0.2 / 100 + 0.2 + 装备暴击/1000 + 门派基础` | 方寸山 +0.10 |
| **命中率** | `(STR × 0.05 + AGI × 0.05 + INT × 0.05) / 100 + Level × 0.2 / 100 + 0.2 + 装备命中/1000` | — |
| **闪避率** | `(AGI × 0.05) / 100 + Level × 0.1 / 100 + 0.1 + 装备闪避/1000` | — |
| **连击率** | `门派基础 + 装备连击/1000` | 天王殿 +0.20 |
| **晕击率** | `门派基础 + 装备晕击/1000` | 五庄观 +0.20 |
| **暴击伤害** | `门派基础` | 方寸山 1.70，其他 1.50 |

> **注意**：装备和法宝上的概率属性以千分数（‰）存储，除以1000后转换为百分比。

### 2.3 门派被动加成

| 门派 | 加成 |
|------|------|
| 天王殿 | 基础连击率 +20% |
| 五庄观 | 基础晕击率 +20% |
| 方寸山 | 基础暴击率 +10%，基础暴击伤害 +20%（1.70） |

## 3. 基础伤害计算流程

### 3.1 攻击阶段总流程

```
攻击开始
  ├─ 命中判定 → 未命中则跳过
  ├─ 动画播放（攻击者移动至目标位置）
  ├─ 基础伤害计算
  ├─ 伤害修正（暴击/技能系数/破军斧等）
  ├─ 防御减伤处理
  ├─ 免伤处理（防御/列阵/通用免伤）
  ├─ 分摊处理（玄武镇岳阵）
    ├─ 易伤修正（×1.1，护盾前计算）
  ├─ 护盾吸收
  ├─ 实际扣血
  ├─ 反弹处理
  ├─ 击杀效果
  └─ 连击判定
```

### 3.2 核心伤害函数

代码入口：`BattleManager.ApplyAttackToTarget()`（普攻和技能共用的伤害应用函数）

### 3.3 命中判定

```csharp
命中率 = 攻击者命中率 - 防御者闪避率
// 命中率 = attacker.HitRate - defender.EvasionRate
if (Random.value < 命中率) → 命中
else → 未命中，跳过伤害
```

#### 命中率公式

```
命中率 = cachedHitRate + tempHitBonus + huiDengHitBonus - hitRateDecrease - 属性减益(命中)
```

#### 闪避率公式

```
闪避率 = cachedEvasionRate + tempEvaBonus - 属性减益(闪避)
```

## 4. 攻击判定流程

### 4.1 基础伤害计算

```csharp
// 1. 基础攻击力差值
有效防御 = 目标防御 × (1 - clamp(忽略防御百分比, 0, 1))
基础伤害 = max(1, 攻击者最终ATK - round(有效防御))

// 2. 伤害系数修正
最终伤害 = round(基础伤害 × 伤害系数)

// 3. 眩晕增伤（五庄观被动）
如果攻击者为五庄观 且 目标处于眩晕状态：
    最终伤害 = round(最终伤害 × 1.1)

// 4. 敛锋增伤（天王殿连击被动）
最终伤害 = round(最终伤害 × (1 + lianFengDamageBonus))
  
// ★ 4.5 妙法承佑最终伤害加成（方寸山）
if (攻击者门派 == 方寸山 && nextAttackDamageBonusStacks > 0) {
    妙法承佑加成 = nextAttackDamageBonusStacks × 0.20  // 每层20%，上限60%
    最终伤害 = round(最终伤害 × (1 + 妙法承佑加成))
}
  
// 5. 道玄缚祟增伤
如果攻击者为五庄观：
    每层属性减益 × 15%，上限75%
    if (debuffCount > 0)
        最终伤害 = round(最终伤害 × (1 + min(debuffCount × 0.15, 0.75)))
```

### 4.2 暴击判定

```csharp
// 暴击率计算
最终暴击率 = GetFinalCritRate()
// = baseCritRate + tempCritRateBonus + mingXinCritRateBonus + xianXianCritBonus 
//   + chanXinCritBonus + nextCritRateBonus - 属性减益(暴击)

if (forceCrit || Random.value < 最终暴击率) → 暴击
```

#### 暴击伤害计算

```csharp
// 方寸山暴击：额外忽略防御10%
if (攻击者门派 == 方寸山 && 暴击) {
    有效防御 = 目标DEF × (1 - (忽略防御百分比 + 0.1))
    基础伤害 = max(1, 攻击者ATK - 有效防御)
    最终伤害 = round(基础伤害 × 伤害系数)
}

// 暴击伤害修正
暴击伤害 = 基础暴击伤害 + 溢出暴击转化(门派不同)
最终伤害 = round(最终伤害 × 暴击伤害)
```

#### 溢出暴击转化

| 门派 | 转化比例 | 说明 |
|------|---------|------|
| 天王殿 | 1:1 | 游刃有余：每溢出10%暴击率 → 10%暴伤 |
| 五庄观 | 1:1 | 成竹在胸：同上 |
| 方寸山 | 1:2 | 得心应手：每溢出10%暴击率 → 20%暴伤 |

```
溢出暴击率 = 最终暴击率 - 1.0
暴击伤害 = cachedCritDamage + 门派加成
```

### 4.3 最终伤害修正

```csharp
// 破军斧增伤（攻击HP>70%的目标）
if (攻击者有破军斧 && 目标当前HP/目标最大HP > 0.7)
    最终伤害 *= 1.3

// 玄冰甲减伤
if (目标有玄冰甲 && Random.value < 0.2)
    最终伤害 = round(最终伤害 × 0.5)  // 伤害减半并反弹50%

// 防御免伤
if (目标处于防御状态)
    最终伤害 = round(最终伤害 × (1 - defenseReduction))  // 默认0.5

// 列阵免伤
if (目标处于列阵状态)
    最终伤害 = round(最终伤害 × (1 - arrayFormationReduction))  // 0.2

// 通用免伤（门派被动、装备、Boss被动等）
最终伤害 = round(最终伤害 × (1 - damageReductionPercent))

// 易伤加成（在护盾吸收之前计算，提高后的伤害直接由护盾吸收）
if (目标有易伤 debuff)
    最终伤害 = round(最终伤害 × (1 + damageTakenIncrease))  // 默认0.1
```

### 4.4 玄武镇岳阵分摊

```csharp
if (攻击者是玩家 && 玄武存活 && 目标是四神兽(非玄武自身)) {
    分摊伤害 = round(最终伤害 × 0.5)
    玄武承担(分摊伤害)     // 玄武 TakeDamage
    目标实际受伤害 = 最终伤害 - 分摊伤害
}
```

### 4.5 护盾吸收

```csharp
护盾吸收顺序：
0. ★ 易伤修正（damageTakenIncrease，在护盾吸收前计算）
1. overHealShield（过量治疗护盾 / 诛仙剑护盾 / 玄甲护体）
2. jinGangSanShield（金刚伞护盾）

// 剩余伤害扣血
currentHP -= 剩余伤害
if (currentHP < 0) currentHP = 0
```

## 5. 伤害修正公式

### 5.1 最终攻击力（GetFinalATK）

```csharp
// 白虎逐血追击
if (角色名 == "白虎") {
    hp百分比 = 当前HP / 最大HP
    攻击力加成 = clamp(1 - hp百分比, 0, 1)  // 每损失1% HP = 1% 攻击力
}

// 妙法承佑（方寸山）— 已改为最终伤害加成，在 BattleManager.ApplyAttackToTarget() 中独立乘算
// 不再在此处参与攻击力计算

// 总攻击倍率
攻击倍率 = 1 + tempAttackBonus + shengShengAttackBonusValue 
          + shadowDeathAttackBonusValue + baiHuBonus

// 杀伐阵光环（白虎存活时四神兽）
if (角色是四神兽 && 白虎存活)
    攻击倍率 += 0.15

// 属性减益
baseATK = 基础ATK × (1 - debuff.reducePercent)  // 攻击力降低10%

最终ATK = round(baseATK × 攻击倍率)
```

### 5.2 防御力（DEF）

```csharp
防御力 = cachedDEF + extraDEF

// 镇岳阵防御加成（四神兽）
if (角色是四神兽 && 玄武存活) {
    防御力 += round(玄武.cachedDEF × 0.30)
}

// 属性减益
if (存在"防御"属性减益)
    防御力 = round(防御力 × (1 - 0.1))  // 默认降低10%
```

### 5.3 速度（CurrentSpeed）

```csharp
速度 = SPD × (1 - 属性减益(速度)) × (1 + 0.1 × windWingStacks + deathPenaltySpeedBonus) 
       × speedMultiplier × (xunJieActive ? 1.2 : 1)
```

## 6. 防御减伤处理

### 6.1 防御状态

| 状态 | 免伤比例 | 特殊效果 |
|------|---------|---------|
| 普通防御 | 50% (`defenseReduction = 0.5`) | 无反伤 |
| 列阵（不动如山） | 20% (`arrayFormationReduction = 0.2`) | 80%概率反击 |
| 门派被动免伤 | 30% | 天王殿/五庄观/方寸山各自独立 |
| Boss被动免伤 | 视具体数值 | 如通天教主50% |

### 6.2 免伤叠加

```
总免伤 = 防御免伤(0/0.5/0.2) + 通用免伤(damageReductionPercent)
伤害 = round(伤害 × (1 - 总免伤))
```

注意：防御免伤与通用免伤是**加法叠加**而非乘法。

### 6.3 防御忽视

```
有效防御 = 目标DEF × (1 - clamp(忽略防御百分比, 0, 1))
忽略防御来源：
  - 基础：0%
  - 敛锋每层: +5%（天王殿连击被动）
  - 方寸山暴击: +10%
```

## 7. 护盾系统

### 7.1 护盾类型

| 护盾类型 | 来源 | 吸收值 | 优先级 | 可叠加 |
|---------|------|--------|-------|-------|
| 过量治疗护盾 | 治疗溢出 / 诛仙剑 / 玄甲护体 | 上限等于MaxHP | 第1层 | 不可叠加（覆盖） |
| 金刚伞护盾 | 金刚伞法宝 | 20% MaxHP | 第2层 | 每回合重置 |

### 7.2 护盾吸收顺序

```
伤害 → 易伤加成(×1.1) → overHealShield → jinGangSanShield → 实际扣血

overHealShield = min(overHealShield, MaxHP)  // 上限为最大生命值
jinGangSanShield = round(MaxHP × 0.2)         // 每回合刷新（ApplyJinGangSanShield）
```

### 7.3 治疗与溢出转化

```csharp
public int Heal(int amount) {
    if (amount <= 0 || IsDead()) return 0;
    int newHP = currentHP + amount;
    if (newHP > MaxHP) {
        int overflow = newHP - MaxHP;
        currentHP = MaxHP;
        overHealShield = min(overHealShield + overflow, MaxHP);
        return amount - overflow;
    } else {
        currentHP = newHP;
        return amount;
    }
}
```

## 8. 暴击系统

### 8.1 暴击率计算

```csharp
最终暴击率 = cachedCritRate 
           + tempCritRateBonus        // 空明心境 +0.30
           + (mingXinActive ? 0.10 : 0)  // 明心见性 +0.10
           + xianXianCritBonus         // 陷仙结界 +0.15
           + chanXinCritBonus          // 禅心入梦 +0.10
           + nextCritRateBonus         // 慧灯永续
           - 属性减益(暴击)
```

### 8.2 强制暴击

**无相慧剑**：当最终暴击率 ≥ 75% 时，本次攻击必暴击。

### 8.3 暴击效果

1. **基础效果**：伤害 × 暴击伤害倍率
2. **方寸山被动 - 妙法承佑**：
   - 暴击时忽视20%防御
   - 为全体友方施加护盾（伤害的30%）
   - 叠加一层"下次攻击最终伤害+20%"（上限3层=60%，在最终伤害阶段独立乘算）
3. **方寸山被动 - 慧灯永续**：回复15%最大生命值，提升15%命中率（2回合）
4. **明心见性**：暴击时自身行动条+20%

## 9. 连击系统

### 9.1 连击率计算

```csharp
连击率 = totalComboChance         // 基础连击率（包含装备）
       + tempComboBonus            // 枕戈待旦 +0.30
       + (lionComboBuffActive ? 0.10 : 0)  // 狮子搏兔双命中
       + (weiZhenBuffActive ? 0.10 : 0)    // 威震山河命中
       - 属性减益(连击)
       - lianFengComboPenalty      // 敛锋每层-10%
```

### 9.2 连击触发机制

```csharp
// 天王殿：允许多次连击（allowMultipleComboThisTurn = true）
最多连击10次，每次判定：
  当前连击率 = GetTotalComboChance()
  if (Random.value < 连击率) → 触发连击
  else → 连击终止

// 非天王殿：最多1次连击
if (Random.value < 连击率) → 触发1次连击
```

### 9.3 连击效果

1. **伤害**：连击伤害系数 = 1.0（100%攻击力），不触发再次连击
2. **生生不息**（天王殿）：每次连击回复15%最大生命值，攻击力+15%（2回合）
3. **敛锋**（天王殿）：每次连击叠加一层：
   - 伤害+10%
   - 防御忽视+5%
   - 连击率-10%
   - 上限10层，持续到本回合结束

### 9.4 保底连击

天王殿被动 - 蓄势待发：
```
if (连击率 ≥ 50% && 本回合未触发任何连击)
    → 强制触发一次保底连击（不可触发再连击）
```

## 16. 反击系统

### 16.1 反击触发条件

```csharp
// 反击概率
if (defender.isInArrayFormation)
    反击概率 = defender.arrayFormationCounterChance  // 80%
else
    反击概率 = defender.counterChance                 // 0%

// 触发时机：被攻击后
if (Random.value < 反击概率) → 触发反击
```

### 16.2 反击伤害

```csharp
反击伤害 = round(反击者ATK × 0.75)  // 固定伤害系数0.75
// 反弹伤害不计算目标的防御减免（但目标减伤效果仍生效）
```

### 16.3 列阵反击

不动如山状态下：
```
自身被攻击时 → 80%概率反击（标准反击）
己方其他成员被攻击时 → 80%概率反击
反击伤害 = round(攻击者ATK × 0.75)
```

### 16.4 迅疾如风（天王殿被动）

```csharp
反击后 → 行动提前10%
currentActionValue += ACTION_THRESHOLD × 0.1
```
