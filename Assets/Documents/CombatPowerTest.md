# 修炼场·战力检定 & 假想敌系统 — 设计文档

---

## 概述

本文档描述修炼场·战力检定系统的功能设计，包括战力测试的核心机制、假想敌配置系统以及关联的数值体系。

**入口**：游戏主界面菜单 → "修炼场"（或主城NPC"战斗分析师"）

### 核心规则
- 战场仅上阵**主角单人**，无队友、无召唤物，全程单人对抗敌人。
- 以**封神演义**截教门人、妖仙、神兽为敌人原型。
- 每层敌人机制严格贴合**ATB回合制**（行动条速度、行动顺序、技能回合冷却、状态干扰），且针对性克制/适配三门派特性，引导玩家利用门派优势破局。
- **敌人MP**：敌人普通攻击同主角；使用技能消耗MP，但视为无限（仅受冷却CD限制）。
- 灼烧/中毒造成最大生命值 5% 的伤害，可叠加，最多两层；DOT伤害不参与暴击计算，不受目标免伤影响。
- 护盾类型多样：金刚伞护盾为20%MaxHP（每回合刷新），过量治疗护盾上限为100%MaxHP，玄甲护体为50%MaxHP（持续4回合）。吸收顺序：易伤修正→overHealShield→jinGangSanShield→实际扣血。

## 引言

### 功能定位
让玩家在可控环境下，直观感受属性数值变化如何影响输出效率与生存能力。支持预设假想敌导入，模拟不同战斗场景。

## 1. 行动值系统（核心）

### 1.1 行动阈值

```
ACTION_THRESHOLD = 500  // 固定行动阈值，每次行动消耗500行动值
```

### 1.2 行动值累积

| 角色 | 累积速率 | 阈值 | 消耗 |
|------|---------|------|------|
| 玩家 | `GetSPD() × dt` | 500 | -500 |
| 敌人 | `e.spd × dt` | 500 | -500 |

SPD=500 时，玩家和敌人均每 1.0s 行动一次（500/500=1.0s）。

### 1.3 速度辅助函数

```
GetActionCost(spd) = max(1, 500 * 100 / max(spd, 1))
// SPD=500 → actionCost=100
// SPD=400 → actionCost=125
// SPD=200 → actionCost=250

GetSPD() = 面板SPD × (1 + sliderSPDOffset) × (迅捷状态 ? 1.20 : 1.00)
```

### 1.4 自拉条系统

所有拉条累积到 `pendingSelfPull`，在 `PlayerTurn()` 末尾统一加到 `playerActionValue`（封顶 `ACTION_THRESHOLD - 1 = 499`），避免立即再动。

| 拉条来源 | 公式 | 值 |
|---------|------|-----|
| 镇岳晕击成功 | `ACTION_THRESHOLD × 0.30` | 150 |
| 明心暴击 | `ACTION_THRESHOLD × 0.20` | 100 |
| 迅疾如风反击 | `ACTION_THRESHOLD × 0.10` | 50 |

### 1.5 推条

```
推条量 = ACTION_THRESHOLD × pushPct
// 五雷轰顶：pushPct=0.30 → -150
```

### 1.6 Tick 流程

每帧（0.016s × speedMultiplier）：
1. 玩家和所有存活敌人累积行动值
2. 处理 DOT 结算
3. 检查敌人行动值 ≥ 500，是则扣 500 并执行敌人行动（break，一帧最多一个敌人行动）
4. 检查短轴/长轴终点
5. 若敌人未行动，检查玩家行动值 ≥ 500，是则扣 500 并执行 PlayerTurn

## 2. 测试模式

### 2.1 输出检定
| 参数 | 说明 |
|------|------|
| 目标 | 打木桩（无限血量） |
| 假想敌数量 | 1~5 |

| 敌人攻击 | 造成1点伤害（仅用于触发反击） |

| 维度 | 行动值 | 等效回合(SPD=500) | 用途 |
|------|--------|------------------|------|
| **短轴** | 600 | 约6次行动 | 爆发期观察、技能拆解 |
| **长轴** | 3000 | 约30次行动 | 整体DPS评估 |

## 4. 技能 CD 系统

### 4.1 规则

| 规则 | 说明 |
|------|------|
| CD 1回合 | 使用技能的当前回合结束后，下回合不可使用，下下回合可使用 |
| CD 2回合 | 使用后冷却2回合（即跳过下两回合），第3回合才可使用 |
| CD 检测 | 若主技能处于 CD 中，自动跳回普攻并输出日志 |
| CD 递减 | 每次玩家行动结束后所有技能 CD - 1（最低 0） |
| MP 检测 | MP 不足时跳回普攻 |

## 5. 门派被动技能实现

### 5.1 天王殿

## 10. 附录：伤害公式

### 10.1 基础伤害

```
基础伤害 = max(1, ATK - 有效防御)
有效防御 = round(DEF × (1 - 防御忽视))
```

### 10.2 伤害修正顺序

```
1. 技能系数 × 技能倍率
2. 眩晕增伤（五庄观：目标眩晕时 ×1.1）
3. 敛锋增伤（×(1 + lianFengStacks × 0.10)）
4. 生生不息增伤（×1.15，若 active）
5. 暴击判定（强制/随机）
6. 方寸山暴击：基础伤害用额外忽视10%防御重算
7. 暴击倍率 × 暴击伤害
8. 溢出暴击转化（天王殿/五庄观 1:1，方寸山 1:2）
9. 易伤修正（五庄观：×(1 + 0.10)，2回合）
10. 免伤修正（×(1 - target.damageReduction)）
11. 护盾吸收
12. 实际扣血
```

### 10.3 反击伤害

```
反击伤害 = round(ATK × 0.75 × (1 - 目标免伤))
// 固定伤害系数，不计算防御减免
```

### 10.4 连击判定

```
连击率 = max(0, 基础连击率 + 临时加成 - 敛锋惩罚)
// 仅天王殿可多次触发连击
// 非天王殿门派最多触发一次连击
```

### 10.5 晕击判定

```
晕击率 = 基础晕击率 + 临时加成 + 镇岳状态加成(+10%)
// 成功→眩晕2回合（被动晕）/ 技能眩晕回合数
```

## 11. 步进模式

- 暂停时可设置"行动后暂停次数"（1~N）
- 每次角色行动后计数 - 1，归零后自动暂停
- 用于单步调试和精确观察战斗流程

## 12. 固定种子

- 随机种子可固定为任意整数
- 固定后战斗完全可复现
- 便于 A/B 测试对比属性变化的影响
